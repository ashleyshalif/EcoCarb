# EcoCarb 🌱
### A Scalable Framework for Carbon Capture Management
*Turning industrial emissions into cement raw material.*

EcoCarb is a plug-and-play, skid-mounted carbon capture concept for MSME factories. It captures flue-gas CO2 and reacts it with steel slag / fly ash to produce precipitated calcium carbonate (PCC), which is sold to the cement and paint industries. It runs as Carbon-Capture-as-a-Service (zero CapEx for the factory).

This repository contains the **software dashboard prototype** (simulated data): live process monitor, waste-coupling flow, economics, scenario simulator, and scalability view.

> Prototype only. All figures are illustrative assumptions, to be validated in a pilot.
